# Preliminary pilot data

Three contrasting AESRs were selected only for a light proposal proof of concept:

- P1 · AESR 2.1 · Hyper-arid · reference LGP <60 days
- P2 · AESR 10.3 · Dry subhumid · reference LGP 150–180 days
- P3 · AESR 16.3 · Perhumid · reference LGP >300 days

Daily CHIRPS-v3 rainfall was compared for 1991–2000 and 2015–2024. These products are E2 derived preliminary evidence and are not full agronomic LGP estimates.
