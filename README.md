# AESR-SHIFT INDIA

**Daily Detection of Agro-Ecological Drift, Growing-Period Transitions and Crop Productivity Risk across India**

This repository hosts the proposal-linked **AESR-SHIFT INDIA Research Observatory**. The dashboard is designed as a reproducible digital companion to the research proposal, with stable section and subsection anchors for cross-referencing.

## Current stage

- Proposal development
- Core temporal concept: daily environmental observations
- Reference framework: 20 Agro-Ecological Regions / 60 official Agro-Ecological Sub-Regions
- Preliminary proof of concept: 3 contrasting pilot AESRs
- Current preliminary evidence maturity: **E2 (Derived)**

## Dashboard structure

- Research case: problem, gap, innovation and central premise
- Preliminary E2 evidence
- Objectives, hypotheses and benchmark
- Data architecture
- Daily-to-dynamic methods
- E0–E5 evidence-maturity framework
- Expected outputs and downloads

See `docs/SECTION_LINKS.md` for proposal-ready permanent anchors.

## Scientific caution

The preliminary rainfall-active-season metric uses cumulative rainfall thresholds (R10–R90) and is **not interpreted as agronomic Length of Growing Period (LGP)**. Full LGP reconstruction requires integration of temperature, evapotranspiration/water balance, soil moisture and validation evidence.
